# 🚀 Portafolio Digital 2026 - Luis Armando Ramírez Cárdenas

¡Hola! Bienvenido al repositorio oficial de mi portafolio profesional. Soy estudiante de la **Licenciatura en Inteligencia de Negocios** (7mo semestre) en la **Universidad Autónoma de Baja California (UABC)**, Facultad de Contaduría y Administración.

Este espacio digital fue diseñado y desarrollado completamente desde cero (sin plantillas) para ofrecer mis servicios técnicos y profesionales, con el objetivo de financiar mis estudios universitarios y aplicar mis conocimientos en el mundo real.

---

## 🎯 Sobre el Proyecto

Este portafolio no es solo una "tarjeta de presentación", es una demostración técnica de mis habilidades en **Arquitectura Web** y **UI/UX**. El sitio está optimizado para la conversión de clientes y la presentación estructurada de proyectos de Inteligencia de Negocios y Ciencia de Datos.

### ✨ Características Principales
- **Diseño "Digital 2026":** Estética moderna con temática oscura (Dark Mode nativo), acentos en neón (Azul y Verde) y fondos en azul marino profundo.
- **Single Page Application (Simulada):** Navegación fluida y dinámica mediante JavaScript puro (`Vanilla JS`) sin recargar la página.
- **Componentes Interactivos:** Sistema de ventanas modales para detallar paquetes de servicios, cronogramas de educación y tarjetas de proyectos.
- **Responsivo (Mobile First):** Adaptación perfecta a cualquier dispositivo móvil, tablet o pantalla de escritorio, incluyendo una barra de navegación con scroll personalizado.

---

## 🛠️ Stack Tecnológico de este Portafolio

* **HTML5:** Semántica y estructura robusta.
* **CSS3:** Variables CSS (`:root`), Flexbox, CSS Grid, animaciones Keyframes y diseño responsivo (`@media queries`).
* **JavaScript (ES6):** Manipulación del DOM, gestión de estados (clases activas) y control de eventos para modales y navegación.
* **Despliegue:** GitHub Pages.
